## Fonctionnalités

- **Recherche** : filtrer les tâches par titre.
- **Filtre par statut** : afficher toutes les tâches, celles à faire ou celles terminées.
- **Compteur** : nombre de tâches affichées.

## Organisation Git

- `main` : version stable du projet.
- `dev` : branche d'intégration.
- `feature/...` : une branche par fonctionnalité.
